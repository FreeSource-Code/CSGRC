## 🌟 Overview
This repository contains the official single-page website for the **Call for Book Chapters** on **Cybersecurity Governance, Risk, and Compliance in the Age of AI and Global Regulation**, published by Bentham Science (Scopus Indexed).

### 🚀 Key Highlights
- **Single Page Architecture**: Everything is contained in a single fast, responsive, and elegant web page (`index.html`).
- **No Login / Sign-up**: Zero authentication overhead or database dependencies. Pure frontend performance.
- **Exact Poster Fidelity**: Every single word, topic, guideline, editor detail, and deadline from the official Bentham Science poster is present.
- **Interactive 3D Visuals**:
  - Interactive 3D Cyber Globe on HTML5 Canvas.
  - Interactive 3D Openable Hardcover Monograph Reader showcasing all 14 chapters.
- **Live Deadline Countdown**: Automatic live countdown to the abstract submission deadline (31 October 2026).
- **Direct Submission Helper**: Built-in 1-click email copy, direct Gmail composer, and Proposal Draft Assistant.

## 🚢 Deployment

### Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository.
4. Leave all settings as default and click **Deploy**.

### Deploy to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Branch: `main` / `root`.
4. Click **Save**.
